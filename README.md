| # | Assignment | Library | Model |
|---|------------|---------|-------|
| 1 | [Text Sentiment](./task1_ml_applications/01_text_sentiment/) | Hugging Face | DistilBERT |
| 2 | [Audio Speech-to-Text](./task1_ml_applications/02_audio_stt/) | Hugging Face | Whisper-small |
| 3 | [Image Object Detection](./task1_ml_applications/03_image_detection/) | PyTorch Hub | YOLOv5s |
| 4 | [Video Object Detection](./task1_ml_applications/04_video_detection/) | PyTorch Hub | YOLOv5s |
| 5 | [Local LLM](./task1_ml_applications/05_llm_local/) | Ollama | Llama 3.2 1B |

**Frameworks used:** Hugging Face Transformers, PyTorch Hub, Ollama.
