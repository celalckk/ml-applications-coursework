# Task 1: ML Applications

This folder contains applications that use pre-trained ML models for 4 different content types, plus a local LLM.

- 01_text_sentiment (Hugging Face)
- 02_audio_stt (Hugging Face)
- 03_image_detection (PyTorch Hub)
- 04_video_detection (PyTorch Hub)
- 05_llm_local (Ollama + Llama 3.2 1B)
